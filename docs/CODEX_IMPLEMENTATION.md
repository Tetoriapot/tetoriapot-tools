# Codex 実装・調整指示書

## 0. プロジェクトの位置づけ

既存の一次創作サイト「TeToriapot」と並ぶ、ツールまとめ用の別館を作る。
企業向けSaaS一覧ではなく、個人創作サイトの延長として見えることを優先する。

本館：
https://tetoriapot.sakura.ne.jp/

公開先（GitHub Pages）：
https://tetoriapot.github.io/tetoriapot-tools/

リポジトリ：
https://github.com/Tetoriapot/tetoriapot-tools

`main` ブランチのルートから配信し、`.nojekyll` を含める。npmやビルドは不要。

---

## 1. 完成イメージ

### 共通

- タイトル：TeToriapot Tools
- ツール画像サムネイルなし
- テキスト中心
- シンプル
- 青・藍・紫系
- 幻想的だが本文は読みやすく
- PC / スマホ両対応

### Dark Mode

- 深い藍色の背景
- シアン系の細い線
- 半透明の濃紺パネル
- 明るい文字

### Light Mode

- 白〜薄青の背景
- 青紫系の線
- 白いパネル
- 濃紺文字

## 2. 現在の実装を壊さず調整する

まず現在の静的実装を起動し、以下を確認すること。

1. index.html が正常表示される
2. テーマ切替が動く
3. 検索が動く
4. カテゴリ絞り込みが動く
5. スマホ幅で崩れない

その後にデザイン調整へ進む。

---

## 3. 視認性最優先

背景に幻想的な装飾を入れる場合でも、本文領域には必ず十分なコントラストを確保する。

禁止：

- 背景画像の上へ直接小さい文字を大量に置く
- 細すぎる本文フォント
- 低コントラストの灰色文字
- 青背景＋青文字
- 装飾優先でクリック領域が分かりづらいUI

---

## 4. トップページ構成

以下の順番を基本とする。

1. ヘッダー
2. 短い説明文と本館リンク
3. 検索
4. カテゴリ
5. ツール一覧
6. フッター

大きな紹介文とヒーロー装飾は置かず、ヘッダーの下に短い説明文と本館リンクをまとめ、その下から検索できるシンプルな構成にする。
説明文と本館リンクは大きなパネルにせず、PCでは横並び、スマホでは折り返してコンパクトに表示する。ABOUTの見出しとナビゲーションは表示しない。
ページのh1はヘッダーのサイト名とする。

更新履歴はヘッダー左上のボタンからダイアログで開く。閉じるボタンとEscキーに対応し、閉じたら呼び出し元へフォーカスを戻す。

不要な長文を増やさない。

---

## 5. 表示設定

### テーマ切替

- ダーク / ライトの2種類
- localStorage保存
- 初回はOSテーマ参照
- 画面右上へ切替ボタン
- ボタンにはテキストまたはaria-labelを付ける

### 文字サイズ

- ヘッダーに小 / 標準 / 大のボタンを置く
- ブラウザの標準文字サイズに対して87.5% / 100% / 125%で表示する
- 選択状態を `aria-pressed` で示し、テーマとは別にlocalStorage保存する
- 保存が拒否されてもページ内の切替は動くこと
- 拡大後もスマホで横にはみ出さず、固定ヘッダーがアンカー先を隠さないこと

---

## 6. ツールデータ

`assets/js/tools.js` を唯一の主要データソースとして扱う。

各ツールは以下を持つ。

```js
{
  id,
  name,
  description,
  category,
  tags,
  url,
  status
}
```

HTMLへ個別に手書きしない。

---

## 7. 検索

検索対象：

- name
- description
- tags

検索はフロントエンドだけで完結すること。
検索ボックスを空にすると全件表示。

将来的には以下も検索対象へ追加可能：

- aliases
- keywords
- englishName

---

## 8. カテゴリ

カテゴリは以下で開始。

- 画像
- テキスト
- TRPG
- 音声
- ゲーム開発
- その他

カテゴリと検索条件はAND検索にする。

例：

「画像」カテゴリを選択中に「カラー」と入力
→ 画像カテゴリ内でカラーを含むものだけ表示。

---

## 9. カード

カードへ画像は入れない。

表示項目：

- ツール名
- 1〜2文の説明
- カテゴリ
- タグ最大3件
- 公開中 / 準備中
- 矢印

PC：2列
スマホ：1列

---

## 10. URL

`url: "#"` は仮データ。
本番公開前に必ず実URLへ変更する。

外部サイトは：

```html
target="_blank" rel="noopener"
```

を使用する。

ヘッダーの下の説明文に並べて本館へのリンクを置く。


本館側にも将来的に以下のような導線を追加する。

---

## 12. 背景アート

ユーザーの簡素化方針に合わせ、大きな紹介エリアと背景アートの表示は削除済み。
提供素材を変換したWebPは `assets/img/` に保管しているが、ページでは読み込まない。
装飾の再追加はユーザーから要望があった場合に検討し、本文の視認性を優先する。

---

## 13. SEO最低限

以下を設定。

- title
- meta description
- OGP
- favicon
- canonical

ツール詳細ページを作る段階になったら各ページ個別titleにする。

## 14. アクセシビリティ

最低限：

- キーボード操作
- `:focus-visible`
- `aria-pressed`
- 検索結果件数 `aria-live`
- ラベル付きinput
- 十分なコントラスト
- 44px前後のタップ領域

- カテゴリ3列
